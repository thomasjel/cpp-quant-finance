# C++ for Quantitative Finance

Exercises and solutions from **"C++ Programming for Financial Engineering"**
(QuantNet / Datasim, Daniel J. Duffy), worked through as part of my transition
into quantitative finance.

## Background

PhD candidate in theoretical physics (UNAM). 
This repository documents my progression learning 
modern C++ from first principles, applied toward quantitative finance.

## Course structure

| Level | Topic |
|-------|-------|
| 1 | Fundamentals — syntax, control flow, functions, recursion |
| 2 | Preprocessor, structs, dynamic memory — introduces `OptionData` |
| 3 | Object-oriented programming basics — classes, constructors/destructors |
| 4 | Operator overloading |
| 5 | Inheritance & polymorphism — abstract classes, virtual functions |
| 6 | Templates / generic programming |
| 7 | STL — containers and algorithms |
| 8 | Boost — smart pointers, statistical distributions, random number generation |
